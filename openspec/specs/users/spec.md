## Purpose

用户管理模块提供系统用户账号的维护能力，涵盖用户查询、新增、编辑、启停用、密码重置与删除等操作，并约束仅「管理员」角色可执行用户管理。密码 MUST 以哈希形式存储，任何界面与接口 MUST 不明文展示密码。系统初始化内置默认管理员账号 admin。

## Requirements

### REQ-USER-001: 用户列表查询（分页+筛选）

系统 SHALL 提供用户分页列表查询能力，列表字段包含用户名、姓名、角色、状态、创建时间（MUST 不包含密码）；并支持按用户名/姓名模糊搜索、角色下拉、状态下拉进行筛选。

#### Scenario: 组合条件查询返回匹配分页列表

- WHEN 用户以用户名或姓名关键词、指定角色、指定状态的组合条件查询用户列表
- THEN 系统返回同时满足全部筛选条件的分页用户列表，列表字段完整且不含任何密码字段，分页信息正确

#### Scenario: 翻页保持筛选条件

- WHEN 用户在已应用筛选条件的用户列表中切换至下一页
- THEN 系统按相同筛选条件返回下一页数据，筛选条件保持不变

### REQ-USER-002: 新增用户

系统 SHALL 支持新增用户，必填字段为用户名、姓名、角色；用户名 MUST 全局唯一；新用户密码 MUST 以哈希存储的默认初始密码写入，状态 MUST 默认为「启用」，创建时间 MUST 自动生成。

#### Scenario: 用户名重复被拒绝

- WHEN 用户提交的用户名与已有用户重复
- THEN 系统拒绝创建并返回用户名重复的校验错误信息

#### Scenario: 校验通过创建成功且状态为启用

- WHEN 用户提交包含全部必填字段且用户名不重复的新用户
- THEN 系统创建用户成功，状态为「启用」，创建时间为当前时间，密码以哈希形式保存

### REQ-USER-003: 编辑用户

系统 SHALL 允许修改用户的姓名、角色、状态、备注等业务字段；编辑时必填字段缺失或用户名与已有用户冲突 MUST 被拒绝。

#### Scenario: 编辑成功保存修改

- WHEN 管理员修改用户姓名、角色等字段并提交合法数据
- THEN 系统保存修改成功并返回更新后的用户信息

#### Scenario: 必填校验失败被拒绝

- WHEN 管理员编辑用户时清空必填字段（用户名、姓名、角色）或提交与已有用户重复的用户名
- THEN 系统拒绝保存并返回校验错误信息

### REQ-USER-004: 启用/停用

系统 SHALL 支持在「启用」与「停用」之间切换用户状态；状态为「停用」的用户 MUST 无法登录使用系统；默认管理员 admin MUST 不可被停用。

#### Scenario: 停用成功后无法登录

- WHEN 管理员将某用户状态切换为「停用」，该用户随后尝试登录
- THEN 系统拒绝其登录并返回账号已停用的提示

#### Scenario: 停用默认管理员被拒绝

- WHEN 管理员尝试将默认管理员 admin 停用
- THEN 系统拒绝该操作并返回错误提示，admin 状态保持「启用」

### REQ-USER-005: 重置密码

系统 SHALL 支持管理员将指定用户密码重置为默认初始密码；密码 MUST 以哈希形式存储，查询与展示 MUST 不返回明文密码。

#### Scenario: 重置密码成功

- WHEN 管理员对指定用户执行重置密码
- THEN 系统将该用户密码重置为默认初始密码（哈希存储）并返回成功提示

#### Scenario: 查询结果不含明文密码

- WHEN 管理员查询用户列表或用户详情
- THEN 返回数据中不包含明文密码字段

### REQ-USER-006: 删除用户

系统 SHALL 允许删除用户，删除操作 MUST 经过用户二次确认；默认管理员 admin MUST 不可删除。

#### Scenario: 非 admin 用户删除成功

- WHEN 管理员对非 admin 用户确认执行删除
- THEN 系统删除该用户及其角色关联，后续查询不再返回该用户

#### Scenario: 删除默认管理员被拒绝

- WHEN 管理员尝试删除默认管理员 admin
- THEN 系统拒绝删除操作并返回错误提示，admin 数据保持不变

#### Scenario: 未通过二次确认不执行删除

- WHEN 管理员触发用户删除但在二次确认中未确认
- THEN 系统不执行删除，用户数据保持不变

### REQ-USER-007: 用户管理权限

系统 SHALL 仅允许「管理员」角色执行用户管理操作（新增、编辑、启用/停用、重置密码、删除）；非「管理员」角色的用户管理请求 MUST 被拒绝。

#### Scenario: 管理员可管理用户

- WHEN 「管理员」角色的用户执行用户管理操作
- THEN 系统允许执行该操作

#### Scenario: 非管理员管理用户被拒绝

- WHEN 非「管理员」角色（如审核员、普通用户）的用户执行用户管理操作
- THEN 系统拒绝该请求并返回权限错误提示

### REQ-USER-008: 默认管理员

系统初始化 MUST 内置默认管理员账号：用户名为 admin，角色为「管理员」，状态为「启用」。

#### Scenario: 初始化后存在可用默认管理员

- WHEN 系统完成初始化数据加载
- THEN 存在用户名为 admin、角色为「管理员」、状态为「启用」的用户，可用默认密码登录
